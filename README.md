# ISO/IEC 27001:2022 ISMS Implementation — UnityTrust Bank Case Study

A complete ISO/IEC 27001:2022 Information Security Management System (ISMS) implementation exercise, built around a fictional digital-first commercial bank case study (**UnityTrust Bank**). Completed as the capstone project for a GRC internship at PKCERT (National CERT Pakistan).

## Overview

This repository documents an end-to-end ISMS assessment cycle: identifying assets and threats, assessing control maturity against ISO 27001 Annex A, building a risk treatment plan, and producing the formal Statement of Applicability required for certification readiness.

**Case study organization:** UnityTrust Bank — a digital-first commercial bank operating core banking, mobile/internet banking, ATM and payment gateways, AML/fraud monitoring, an open banking API layer, and cloud-hosted analytics.

## Methodology

The assessment followed a four-phase approach:

1. **Asset Identification** — catalogue critical assets and rate each by Confidentiality, Integrity, and Availability (CIA) impact; identify the threats and vulnerabilities facing each one.
2. **Gap Analysis** — assess current security practices against all 93 ISO/IEC 27001:2022 Annex A controls and identify specific, prioritized gaps.
3. **Risk Treatment Plan** — convert each risk into a Likelihood × Impact risk score, and define a **Mitigate** treatment: a specific control, an owner, and a target completion date.
4. **Statement of Applicability (SoA)** — formally declare which of the 93 Annex A controls apply, why, and their current implementation status.

## Key Findings

- **93 Annex A controls assessed** — 27 High priority gaps, 47 Medium, 19 Low
- **26 assets identified** — 5 rated Critical, 12 High priority
- **26 risks treated** — 100% assigned a Mitigate treatment with an owner and timeline
- **93 of 93 controls** determined applicable to the ISMS scope; 92 partially implemented, 1 not yet implemented
